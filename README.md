# Ikk Desktop

<img src="Telegram/Resources/branding/ikk.png" width="160" alt="Ikk app icon">

Ikk Desktop is an independent Telegram client built with Qt, based on
[Telegram Desktop](https://github.com/telegramdesktop/tdesktop).

- [Feature requirements](docs/ikk/requirements.md) ·
  [Design and roadmap](docs/ikk/design.md)
- [Brand assets and application identity](BRANDING.md)
- Build instructions: [macOS](docs/building-mac.md),
  [Windows](docs/building-win.md), [Linux](docs/building-linux.md)
- [Source](https://github.com/ikk-dev/Ikk) ·
  [Releases](https://github.com/ikk-dev/Ikk/releases)

The upstream CMake target remains `Telegram`; the resulting desktop executable
is named `Ikk`. Builds require your own Telegram API credentials for
distribution. Upstream automatic updates are disabled; no Ikk update service
or store distribution has been configured.
